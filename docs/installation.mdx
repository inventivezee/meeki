## Current availability

The CLI includes the `meeki mcp` server in the same executable.

<Warning>
  Homebrew, standalone release binaries, and Windows package-manager distribution are forthcoming. Do not rely on those channels yet.
</Warning>

## Install from the desktop app

On macOS, open **Settings → Developers** and select **Install**. Meeki installs the bundled command at `~/.local/bin/meeki` without sending data anywhere.

If your shell cannot find `meeki`, add `~/.local/bin` to `PATH`:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

## Build from source

To build the CLI yourself instead:

```bash
git clone https://github.com/inventivezee/Meety.git
cd meeki
cargo install --locked --path apps/cli
meeki --version
```

`cargo` installs the executable into its configured binary directory, normally `~/.cargo/bin`. Add that directory to `PATH` if your shell cannot find `meeki`.

## Connect to local data

By default, the CLI looks for `meeki/app.db` in your operating system's application-data directory. It also recognizes legacy Meeki locations.

Open the desktop app once before using the CLI. For a custom database location, pass a global option or environment variable:

```bash
meeki --db-path /path/to/app.db --json meetings list
MEEKI_DB_PATH=/path/to/app.db meeki --json meetings list
```

If you have an Meeki data directory containing `app.db`, use:

```bash
meeki --base /path/to/meeki-data --json meetings list
```

The CLI opens the database in read-only query mode. It does not create a database or run migrations.
