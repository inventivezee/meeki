## Updates

- Say when an update is waiting. Updates have always downloaded on their own, but the only sign was a small circle in the sidebar, so a finished download could sit ready indefinitely. There is now a prompt at the bottom left that installs it in one click, and it can be dismissed
- Keep checking after your Mac has been asleep. The half-hourly check ran on a timer that stops while the Mac sleeps, so closing the lid partway through a wait left the rest of it to run the next morning — a night counted for nothing, and a Mac that sleeps every night could go a long time without ever checking
- Retry the check made at launch. Opening Meeki at login usually beats Wi-Fi connecting, and a single failed attempt used to mean waiting half an hour for the next one

## Recording

- Start a recording from anywhere. The record button lived in a note's own header, so there was no way to begin one from settings or the changelog. It now sits in the sidebar next to New note and creates the note it records into
- Start a recording by right-clicking Meeki in the Dock

## What's new

- The release notes you are reading now appear. This panel had never shown anything: it looked for notes matching the running version among a set of files left over from before the app was renamed, and none could ever match

## Elsewhere

- Removed a second Quit from the Dock menu. macOS adds its own, and ours sat directly above it doing exactly the same thing
