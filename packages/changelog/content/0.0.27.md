## Improvements

- Progress now counts across your whole library — "147 of 683 transcribed" — instead of restarting from zero every time the run is started. A long import reads as progress made rather than a handful of recordings, and the number survives stopping, restarting and quitting
- A recording no longer waits five minutes for its summary to begin before moving on. That wait was set for a language model loading from cold; it was costing time on every recording

## Fixes

- When a recording cannot be processed, the reason is now written to the log file rather than only to a developer console that cannot be opened in a normal build. Summaries that fail during an import can finally be diagnosed
