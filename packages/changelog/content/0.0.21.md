## Importing

- Recordings you have already imported are now recognised and skipped, by content rather than by filename — so a renamed or relocated copy of the same audio is caught too. Files chosen from the picker are checked before they are copied; dropped files are checked afterwards and the extra note is removed. You get a count at the end, not a question for each one
- Two copies of the same recording inside one selection collapse to a single note
- Your Mac no longer sleeps while an import is copying. Transcription already held sleep off; the copying, which is the longer half of a large import, did not

## Fixes

- Summaries failed during a bulk run with "error sending request" or "AI generation did not return any text". Meeki was releasing the language model for the next recording while the previous summary was still being written. It now waits for each summary to actually finish
