## Importing

- **Settings → Recordings** now has an **Import** button beside Export all. It opens the same picker as **Bulk import recordings** in a note's **⋯** menu, so choosing several files still asks whether to transcribe and summarize them

## Fixes

- The app icon was still the old artwork in the installer window, in Finder and in Applications. It only turned into the new one once the app was running. Every copy of the icon had been updated except the one macOS actually reads, so all of them now match
- The installer window credited the wrong company. It now reads Innovate Abundance LLC

<banner variant="info">
macOS caches app icons. If Finder still shows the old icon after updating, log out and back in, or run `killall Finder Dock` in Terminal.
</banner>
