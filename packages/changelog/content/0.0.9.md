date: "2026-08-07"
summary: "Meeki 0.0.9 stops offering downloads for models you already have, keeps paused transfers resumable, and downloads the transcription model you actually picked."
---

## Downloads

- Stop re-downloading a model that is already on your Mac. Four places in the app could quietly refetch a complete model — the setup card, the summary empty state and both model lists — and because the bytes land in a temporary file while the finished one keeps working, there was nothing to see but a progress bar that should not have been there
- Verify a finished download against its expected size before it replaces a model you already have. These models ship without checksums, so this is the only check standing between an interrupted transfer and your working weights
- Show real byte counts while a download is paused, instead of "0 bytes of 0"
- Keep a paused or interrupted download resumable after updating Meeki

## Pausing and resuming

- Pausing a download no longer reports it as failed
- Resume works. The button said "Resume" but was disabled in exactly that state, so a download waiting to retry could only be cancelled or waited out
- A paused model is no longer selected for use while its download is incomplete

## Transcription

- Download and use the batch transcription model you chose. Picking the smaller Qwen3 ASR 0.6B to save disk fetched the 1.7B one instead and left the setup panel waiting for a model nothing had been asked to fetch

## Elsewhere

- The model lists no longer announce "downloaded" the moment a transfer starts, and no longer offer a Download button for the rest of it
- The summary setup offers to use a model that is already on your Mac, rather than to download it again
