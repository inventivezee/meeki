## Import a folder of recordings

- **Bulk import recordings**, in the **⋯** menu on any note, takes a whole folder at once. Select as many files as you like in the picker — each becomes its own note
- Before anything is copied, Meeki asks whether to **transcribe all** and **summarize all** of them. Leave both on and the whole batch is processed for you; turn them off to import the audio and decide later
- Importing shows a running count and can be stopped at any point. Recordings already imported keep their notes
- Processing runs one recording at a time and can take many hours for a large batch. Stop it whenever you like — restarting picks up exactly where it left off, even after quitting the app or a restart
- A recording that cannot be read is reported and skipped rather than stalling everything behind it
- Dragging more than a couple of dozen files, or more than a gigabyte, now points you at the picker instead of struggling. Dropped files have to be copied through the app itself; the picker hands over the files directly, which is what makes a folder-sized import possible

## Long meetings

- Meetings longer than about an hour produced no summary at all. The model can only hold so much at once, and a long transcript overran it — the request failed and nothing was kept
- Meeki now sizes that working memory to the recording in front of it, growing it as far as your Mac's memory allows, so long meetings summarize like any other
- Shorter meetings are unaffected and use no more memory than before
