## Working through imported recordings

- Your Mac no longer sleeps while Meeki is transcribing a batch. A few hundred recordings is hours of work, and sleeping partway through did not pause it so much as strand it
- How many recordings still need a transcript now lives in **Settings → Recordings**, next to Import and Export, with progress and a Stop while a run is going. **Upload a Recording** is back on the home screen where it was

## Fixes

- Updates could fail with "cached update not found" and keep failing on every retry, which is what happened if a release came out after Meeki had already downloaded an earlier one. It now fetches what it is missing instead of giving up
- There were two places offering to install an update: a small circle in the sidebar and the prompt at the bottom of the window. The circle is gone
