---

## Downloads

- Fix a download that could report success while incomplete, replacing a model that already worked. The model would keep answering until the next restart and then fail to load
- Retry instead of accepting a response that ends early

## Transcription models

- Stop a sleeping Mac from using up a download's retries. Closing the lid or losing Wi-Fi counted against a fixed number of attempts, so a transcription model could fail permanently overnight for a reason that fixes itself. Waiting for the network back no longer costs an attempt
- Recover from a transcription download that gives up. The setup card could be left showing "Preparing download" with no progress, no way to retry and no way out except quitting Meeki

## Elsewhere

- New app icon
- The setup card describes only the models you are actually missing, and calls them by the same names used everywhere else in the app
- A download that stalls is judged on whether it is still making progress, rather than on a fixed deadline that a slow connection could not meet
