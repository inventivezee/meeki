## App icon

- Fix the old icon still appearing in the Dock, in Finder and on the install window. The artwork had been replaced everywhere except the copy used on Macs set to light appearance, so whether you saw the right icon depended on your appearance setting

## Recording

- **New Recording** now sits beside **Resume** in a note's header. Resume adds to the note you are looking at, which was previously the only thing a finished note offered — starting a separate recording meant leaving the note first. It appears only where the two actually do different things, never mid-recording
- The record button in the sidebar is a filled red circle. As a plain grey microphone among other grey icons it read as decoration rather than the one control there that starts recording

## Settings

- Open settings from a note's **⋯** menu, landing on AI Models. Changing which model transcribes or summarises no longer means leaving the note to find the sidebar first
- **Delete Note** is separated from the items above it, so the new entry does not sit flush against a destructive action
