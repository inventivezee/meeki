summary: "Meeki 0.0.23 stops the language model being loaded twice for every recording, which is what made summaries fail during long runs."
---

## Fixes

- Meeki could start two copies of the language model at once — once for the recording being processed, once for the check that runs every few seconds — and each loaded several gigabytes of weights. The second one could shut down the first mid-summary, which is why summaries failed part-way through a long run with a connection error. Only one starts now
- Working through a batch should also be quicker, since each recording no longer loads the model twice

## Memory

- The graphics memory Meeki keeps for transcription is now sized to your Mac: unchanged on machines with 16 GB or less, and more generous above that, up to 8 GB on a 64 GB Mac. Transcription on a roomy machine was being held to a limit meant to protect a small one
